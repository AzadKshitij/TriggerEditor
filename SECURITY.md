# Security policy

Trigger Designer is in alpha. Please report security problems privately.

## Reporting a vulnerability

Email **azadkshitij08302001@gmail.com** with the subject line
`Trigger Designer security`. Do not open a public issue for a vulnerability.

Include:

- the version (for example `0.1.0a1`), and how you obtained it;
- the steps that trigger the problem, with a minimal `.tds` workflow if one is needed;
- what you expected to happen and what happened instead.

Do not attach real business data. Describe the shape of the data instead.

## What to expect

This is a one-maintainer project. The maintainer aims to reply within seven days.
Fixes for confirmed problems ship in the next alpha, and the release notes name the
issue once it is fixed.
