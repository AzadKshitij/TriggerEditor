# Trigger Designer v0.1.0-alpha.1

**Alpha.** A first public build for testing. Expect rough edges. Please report what
you find using the [bug report template](https://github.com/AzadKshitij/TriggerEditor/issues/new/choose).

## Download

- `TriggerDesigner-0.1.0a1-windows-portable.zip`: the program for Windows 10 or 11, 64-bit.
- `SHA256SUMS.txt`: checksums for the files above.

There is no installer and no Linux build in this alpha. Unzip the archive and run
`TriggerEditor.exe`. The steps are on the [install page](https://azadkshitij.github.io/TriggerEditor/install/).

Check the download with `Get-FileHash` and compare the result with `SHA256SUMS.txt`.

## What is in this alpha

- A node canvas for data checks: read, clean, join, transform, audit and write.
- Audit nodes for duplicates, gaps, Benford's law, sampling and risk filters.
- A run record for each Run, with a verify button and an HTML report.
- Workpaper Output for a formatted Excel workpaper.
- A command-line program, `trigger-designer-cli`, for unattended runs. It is not
  included in the portable zip; see the [command line guide](https://azadkshitij.github.io/TriggerEditor/guide/cli/).
- How-to posts: [blog](https://azadkshitij.github.io/TriggerEditor/blog/).

## Known issues

- **Crash with code `0xC0000409`.** Under heavy workloads (large files, many nodes at
  once) the program can close without an error message. Windows records it as an
  application fault. Save often, and report the steps.
- **Windows shows a warning on first start.** The alpha is not code-signed. Click
  **More info**, then **Run anyway**. See the install page.
- **No update check.** The program does not contact the internet. Watch this releases
  page for new versions.
- **Settings and logs are per user.** They live in `%APPDATA%\Trigger Designer`, not
  beside the portable exe.
