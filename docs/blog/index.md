# Blog

Short how-to posts for Trigger Designer. Each post follows one task from start to
finish on the portable build, `0.1.0a1`.

- **Your first workflow: find duplicate rows in a CSV.** Read a file, tidy the
  column names, and find duplicates.
- **Run a workflow and check the audit trail.** Run it, verify the record, and export
  an HTML report.
- **Write a result to a file.** Use File Output to save what a workflow produced.

The posts are written for the alpha. If a step does not match what you see, check
[Install](../install.md) and open an issue.
